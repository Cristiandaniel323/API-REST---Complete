# Módulo Medias - Frontend

Frontend administrativo para el módulo Media del proyecto de películas.

## Requisitos
- Tener funcionando la API REST en http://localhost:3000
- La API debe exponer /api/media, /api/genero, /api/director, /api/productora y /api/tipo.

## Ejecución
Abre `index.html` desde un servidor local (por ejemplo, Live Server de VS Code). No se recomienda abrirlo directamente con `file://` porque el navegador puede bloquear las peticiones CORS.

## Pantallas incluidas
- Listado y consulta de medias.
- Búsqueda por título/serial.
- Filtro por tipo.
- Registro de nueva media.
- Edición de media.
- Eliminación con confirmación.

Los campos y endpoints se basan en el caso de estudio y en la API del repositorio proporcionado.
